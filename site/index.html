One copy of the game. Everyone gets a turn.

You run the game on your PC. Friends open a link in their browser and send their keyboard, controller or phone to it. Everyone watches your Discord screen share.

Download for Windows

Windows 10 or 11. Free and open source (MIT).

How it works

  1. Start a session

    Open your game, pick its window in PassTheStick, and press Start. You get a six-character room code and an invite link.

  2. Send the link

    Paste it in Discord. Friends click it and they are in. Nothing to install, no account, no ports to open.

  3. Pass the stick

    Only the player holding the stick controls the game. Pass it with a hotkey, the tray icon, or the Pass button, and take it back the same way.

PassTheStick sends input only. It does not capture or stream your screen. The picture your friends see is the Discord screen share you already have open.

Ways to play

Wii Sports bowling over the internet

Run Dolphin with Wii Sports. A friend opens the link on their phone, taps Use phone motion, and swings it like a Wii Remote. The next friend takes a turn. Set up phone motion in Dolphin.

The deathless relay

Souls, a horror game, any run where dying means the next person goes. One key passes the stick the moment someone dies, so nobody alt-tabs mid-boss.

Two or four on one machine

A local multiplayer game, a fighting game, an emulated party game. Each guest gets their own virtual controller at the same time. This needs ViGEmBus on the host.

A room full of people

Guests can ask for the stick and you approve with the same key you use to pass. Good for a Discord stage with ten people and one console.

The idea of everyone controlling one screen is not new. Pop did it for pair programming. PassTheStick applies it to games and keeps it to input.

Questions

Does my friend need to install anything?

No. They open your link in any current browser. Controllers work through the browser. On a phone they get on-screen buttons, and they can turn on phone motion for games that read it.

What about lag?

Input goes straight from your friend's browser to your PC when their network allows it, so it adds the internet round trip between the two of you and nothing else. The page shows whether you are connected directly and the measured round trip. If a direct link is not possible, input goes through a small relay server, and only the player holding the stick can send that way. I have not published real-world numbers yet.

Do I need to install a driver?

Not for keyboards. Virtual controllers need ViGEmBus. The project is archived but its last release still works, and PassTheStick tells you if it is missing. Setup does not install it for you.

Will it get me banned?

Possibly, in online games. Virtual controllers and injected keys look like cheating tools to kernel-level anti-cheat. Use PassTheStick for single-player and local games only. It is not built for competitive or online modes.

What can the people I invite see or do?

They can send input to the one window you picked, and only while they hold the stick. Their keyboard is captured only while they click the capture box on the page, with a visible badge, and holding Escape for a second stops it. The room code is random and not stored by the website. You can end the session at any time.

Does it work on Mac or Linux?

Guests can use any system with a browser. The host runs on Windows today. The code is split so a Linux host is possible later, but it does not exist yet.

What if the game runs as administrator?

Windows blocks input from a normal program to an elevated one. PassTheStick notices this and tells you to restart it as administrator. It does not ask for that on every launch.
