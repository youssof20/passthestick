Three steps, about 30 seconds

  1. Start a session

    Pick your game window and press Start. You get a room code and an invite link.

  2. Send the link

    Paste it in Discord. Friends click it and they are in. No install, no account.

  3. Pass the stick

    Only the holder controls the game. Pass it with a hotkey and take it back the same way.

PassTheStick sends input only. It never captures or streams your screen.

Questions

Does my friend need to install anything?

No. They open your link in a current browser. Controllers work through the browser, and phones get on-screen buttons and optional motion.

What about lag?

Input goes straight from your friend's browser to your PC when their network allows it, so it adds only the internet round trip between you. The page shows whether the link is direct and the measured round trip. If a direct link is not possible, the holder's input goes through a small relay server. I have not published real-world numbers yet.

Do I need a driver?

Not for keyboards. Virtual controllers need ViGEmBus, and PassTheStick tells you if it is missing.

Will it get me banned?

Possibly, in online games. Anti-cheat can flag virtual controllers and injected keys. Use it for single-player and local games only.

What can invited people do?

Send input to the one window you picked, and only while they hold the stick. Their keyboard is captured only while they click the capture box, and holding Escape for a second stops it. Chords that leave the game, such as Alt+Tab and Ctrl+Esc, are blocked. You can end the session at any time.

Does it work on Mac or Linux?

Guests can use any system with a browser. The host runs on Windows only.

What if the game runs as administrator?

Windows blocks input from a normal program to an elevated one. PassTheStick tells you to restart it as administrator when that happens.
