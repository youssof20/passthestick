Get started

This takes about five minutes the first time. You need a Windows 10 or 11 PC that runs the game, and Discord or another way to share your screen. Your friends need a browser.

Install

Download the latest release from GitHub Releases and run it. The first launch shows a short setup: pick the game window, then choose keyboard only or controllers too.

Keyboard sessions need no drivers. Controllers need ViGEmBus. Setup checks for it and tells you where to get it if it is missing. Restart the PC after installing it.

Start a session

  1. Open your game first, so its window exists.
  2. In PassTheStick, search for the game in the window list and press Use this window. Input only goes to this window.
  3. Press Start a session. You get a room code and an invite link.
  4. Press Copy invite link and paste it in Discord. Start your screen share.

What your friends do

  1. Click the link and type a name.
  2. Wait for you to pass them the stick. They see who has it at the top of the page.
  3. With the stick, a keyboard player clicks the capture box and types. A controller works as soon as it is plugged in and a button is pressed. On a phone, the page shows on-screen buttons.
  4. To stop the keyboard capture, hold Esc for one second.

Before you start playing, ask each friend to press Test my controls. You see their buttons light up in a panel in PassTheStick, and they see what arrived. Nothing in test mode reaches the game.

Passing the stick

  • Ctrl + Shift + Right hands the stick to the next player: you, then the guests in order, then you again.
  • If a guest has asked for the stick, the same key gives it to them first.
  • Ctrl + Shift + Left takes the stick back at once.
  • The window buttons and the tray icon menu do the same. Closing the window while you host hides it to the tray, so a stray click does not end the session.

When the stick moves, every key and button the previous player was holding is released, so nothing gets stuck.

If the game runs as administrator

Windows does not let a normal program send input to an elevated one. If your game was started as administrator, PassTheStick shows a warning. Close it and start PassTheStick as administrator too.
