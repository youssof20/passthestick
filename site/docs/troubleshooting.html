Troubleshooting

A friend cannot join

  • "That code is wrong or the session has ended." The room closed. It ends 60 seconds after you leave and after 30 quiet minutes. Start a session and send the new link.
  • "This page and the host run different versions." Update PassTheStick and reload the page.
  • "Too many attempts." Wait a minute. Joining is limited to five tries a minute per address.
  • "This session is full." A room holds eight guests.

Keys do nothing in the game

  • Check the Game window card. It should say input is going to the window. If it says the game is not in front, click the game once. Input pauses on purpose while another window has focus.
  • Check that the friend holds the stick. Only the holder's input goes to the game.
  • If PassTheStick shows an administrator warning, restart it as administrator.
  • Ask the friend to run Test my controls. If their keys light up in your test panel, the connection works and the problem is the game window.

The test shows nothing

Test mode needs a direct connection. If the page says it is using the room server, it only passes the stick holder's input, so the test cannot work. A different network, or turning off a VPN, usually gets a direct connection.

Controllers do not work

  • Guests need ViGEmBus installed on the host, and the setup choice must be controllers, not keyboard only.
  • Restart the host PC after installing ViGEmBus.
  • The browser reads controllers only after a button is pressed on them. Press a button, then look at the test panel.

Phone motion does not move

See Dolphin and phone motion. On an iPhone, allow the motion permission when the page asks.

A key or button seems stuck

Every held key and button is released when the stick moves, when a player leaves, when the game loses focus, and after three quarters of a second without input from the holder. If something still seems stuck, take the stick back with Ctrl + Shift + Left, then report it.

Report a problem

Open an issue on GitHub and say what you did, what you expected, and what happened. Include your Windows version and the game.
