Run your own server

Friends join through a small signaling server. It introduces your PC and your friend's browser to each other and carries input only when a direct connection fails. The project's server is one Cloudflare Worker with one Durable Object per room. You can run the same code yourself.

Try it on your own PC

cd server/worker
npm install
npx wrangler dev --port 8787

PassTheStick uses http://127.0.0.1:8787 as its server address by default in development builds. To test the guest page locally, build it and serve the site folder:

cd web/guest
npm install
node build.mjs
cd ../../site
python -m http.server 8123

Then open http://localhost:8123/join/.

Deploy it

cd server/worker
npx wrangler login
npx wrangler deploy

This needs a free Cloudflare account. Wrangler prints the address of your Worker. Put that address in PassTheStick under Server address, in the setup that appears before you start a session.

Build the guest page for your server so it does not need a query string:

PTS_SIGNALING_URL=wss://your-worker.example.workers.dev node web/guest/build.mjs

Host the files in site anywhere that serves static pages. Invite links point at the page named by the SiteUrl field in %LOCALAPPDATA%\PassTheStick\settings.json, and carry your server address in the link when it differs from the default.

What it limits

  • Up to eight guests per room.
  • Six-character room codes from a random source, with no look-alike letters. A room ends 60 seconds after the host leaves, or after 30 quiet minutes.
  • Message size, message rate and join attempts are capped per connection.
  • The host and each guest hold a secret token that the server stores only as a hash.

A version of the server for people who do not use Cloudflare, such as a small Node program with a Dockerfile, is planned and does not exist yet.
