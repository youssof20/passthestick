Dolphin and phone motion

Wii Sports bowling, tennis and golf read motion. PassTheStick turns a friend's phone into a motion source for Dolphin, so they can swing it like a Wii Remote.

Status: the PassTheStick side of this follows the DSU protocol and is tested against it. It has not yet been checked against every Dolphin version, and Dolphin's menu wording changes between releases. If a label below does not match your version, look for the DSU Client and the motion mapping fields.

How it works

PassTheStick runs a small DSU server on your PC at 127.0.0.1, port 26760. It listens on your own machine only. Dolphin connects to it as an alternate input source and reads each guest's phone as a controller. The first guest is slot 0, the second is slot 1, and so on up to four.

Set up Dolphin once

  1. In Dolphin, open Controllers.
  2. Under Alternate Input Sources, enable DSU Client and add a server with address 127.0.0.1 and port 26760.
  3. Set Port 1 to Emulated Wii Remote and open Configure.
  4. Choose the DSU device for the first guest in the device list (it starts with DSUClient/0).
  5. In the motion sections (accelerometer and gyroscope), map the matching DSU motion inputs. Dolphin's own motion mapping dialog shows live values while you move the phone, which is the easiest way to check each axis.
  6. Buttons still come from the keyboard or controller the guest sends. Map the Wii Remote buttons to those as usual.

On the phone

  1. Open the invite link and join.
  2. Tap Use phone motion. An iPhone asks for permission to read motion. Allow it.
  3. Keep the screen on. The page asks the phone to stay awake.
  4. When you pass the stick to this guest, their motion starts reaching Dolphin. Motion from anyone who does not hold the stick is ignored.

If nothing moves

  • Check that PassTheStick started its motion server. If another program already uses port 26760, PassTheStick says motion will not reach emulators.
  • Make sure the guest holds the stick and the Dolphin window is in front.
  • On iPhone, motion needs a secure page (https). Use the hosted link, not a plain http address.
